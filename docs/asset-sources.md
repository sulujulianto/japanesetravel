# Demo Asset Sources

The images below are local demo assets for the JapanTravel portfolio catalog. They were downloaded from Unsplash, cropped to practical catalog dimensions, converted to WebP, and committed to the repository so the application does not hotlink third-party files at runtime.

- Platform license: [Unsplash License](https://unsplash.com/license)
- Access date: June 11, 2026
- Destination output: 1200 x 800 WebP
- Souvenir output: 900 x 900 WebP
- Usage: illustrative portfolio demo content, not evidence of a commercial partnership or an exact retail listing

Attribution is not required by the Unsplash License, but creator and source-page details are retained here for traceability.

## Replacement Guidance

Admin uploads continue to use the configured media disk and replace the seeded demo path with an uploaded file path. Before replacing an image, confirm that the new asset is owned by the project owner or has a license that permits repository and portfolio use. Record replacement sources in this manifest.
